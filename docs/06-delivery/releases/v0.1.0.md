# Neutrino Desktop v0.1.0

首个 Flutter + Dart 正式版本，适用于 Windows x64 和 macOS Intel / Apple Silicon。

## 本次内容

- 独立 Dart 网络内核与按需启动的 Flutter 界面，关闭主窗口后继续保持连接并释放界面内存；普通最小化仍保留界面。
- 连接配置、License、TLS、TCP/UDP 转发、自动重连、状态和日志，兼容原 Java 客户端协议；端口映射继续在既有管理后台配置。
- 支持导入 Java 客户端 YAML/JSON 配置，凭证使用系统安全存储。
- 复用原 App 的透明图标；托盘右上角在连接成功时显示绿点，其他状态显示灰点。
- 原生托盘提供打开界面、查看日志、连接/断开和退出入口；收起界面后仍可更新连接状态。

## 下载与使用

- Windows：完整解压 `windows-x64.zip`，运行 `Neutrino/neutrino_proxy_client_desktop.exe`，保留同目录全部 DLL 和资源。
- macOS：打开 `macos-universal.dmg`，将 Neutrino 拖入 Applications；也可使用完整 `.app` ZIP。
- `SHA256SUMS` 和 `release-manifest.json` 记录下载文件的校验值、版本和来源提交。
- 升级时从旧托盘选择“退出应用”后再打开新版；关闭主窗口不会退出后台内核。

## 验证范围

按用户明确要求，本次正式发布跳过自动化测试及分析步骤，只执行构建、打包、签名与产物完整性检查。此前 Windows 开发阶段测试记录不等于本次发版重新测试；macOS 交互、真实服务端长时间运行尚未完成实机验收。

Windows 未配置商业代码签名；macOS 使用 ad-hoc 签名，未做 Apple 公证。运行不需要 Java、Rust、Node.js 或 Flutter SDK。
